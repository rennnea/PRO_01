| KPI                 | Definition               | Formula                   | Grain            |
| ------------------- | ------------------------ | ------------------------- | ---------------- |
| Total Cost          | Expenses + resource cost | `expense + resource_cost` | Project          |
| Budget Utilization  | Cost relative to budget  | `total_cost / budget`     | Project          |
| Remaining Budget    | Unused budget            | `budget - total_cost`     | Project          |
| Gross Margin        | Revenue minus cost       | `revenue - total_cost`    | Project          |
| Resource Cost       | Employee cost            | `hours × hourly_cost`     | Employee/Project |
